# 일지정리

자원봉사 거점캠프의 월별 활동일지와 출장 사진을 정리하는 웹앱입니다. 날짜별 기록을 작성하고, 한글 문서(HWPX)와 출근부용 CSV 파일을 내려받을 수 있습니다.

## 사용 방법

1. 화면 위에서 봉사자 이름을 입력하고 거점을 고른 다음 ‘이름·거점으로 일지 작성’을 누릅니다. 선택한 날짜에 일지가 자동으로 만들어집니다. 저장한 봉사자는 이름 입력칸에서 다시 선택할 수 있습니다.
2. GitHub Pages 버전에서는 PDF·JPG·PNG·HWP·HWPX 파일을 원본으로 첨부할 수 있습니다. 이 버전은 파일 내용을 자동으로 읽지 않습니다. PDF·사진·HWP·HWPX 자동 입력은 [자동 입력 사이트](https://volunteer-journal-yayan.ohjiye.chatgpt.site)에서 이용해 주세요.
3. ‘작업 저장’을 누릅니다. 기록과 첨부 파일은 사용 중인 브라우저의 localStorage에 저장됩니다.
4. 각 날짜를 확인 완료한 뒤 월별 한글 문서나 출근부 자료를 내려받습니다.

‘거점 운영현황’에서는 활동 단체를 추가·수정하고 저장할 수 있습니다.

GitHub Pages 버전에서는 입력 내용과 첨부 파일이 사용 중인 브라우저에 저장되며 서버로 전송하지 않습니다. 자동 입력 사이트에서는 인식을 위해 원본 파일이 OpenAI API로 전송됩니다. 브라우저 자료를 지우거나 다른 컴퓨터·브라우저를 사용하면 기존 기록을 볼 수 없습니다. 첨부 파일이 많거나 크면 저장 공간이 부족할 수 있으므로 중요한 자료는 문서로 내려받아 보관하세요.

## GitHub Pages에 올리기

`GitHub-Pages-업로드.zip`에는 공개할 파일만 들어 있습니다. 압축을 풀고, 그 안의 파일과 `assets` 폴더를 올리세요. ZIP 파일 자체를 올리는 방식은 아닙니다.

공개할 파일은 `index.html`, `assets` 폴더, `.nojekyll`, `README.md`, `.gitignore`, `LICENSES.txt`입니다. 이 파일들만 저장소 맨 위에 올리고, GitHub Pages의 배포 위치를 해당 브랜치의 `/ (root)`로 선택하세요.

이 폴더의 `work`, `volunteer-journal` 등 작업용 폴더는 올리지 마세요. `.gitignore`는 Git을 통한 업로드에서 제외하며, 웹 화면에서 직접 올릴 때는 파일을 직접 골라야 합니다.
