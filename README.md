# 일지정리

자원봉사 활동을 날짜별로 정리하고 한글 문서나 출근부 자료로 내려받는 웹앱입니다.

## 사용 방법

1. 월을 선택하고 활동가 이름을 직접 입력한 뒤 ‘이름 적용’을 누릅니다.
2. PDF·HWP·HWPX·JPG·PNG 일지를 올릴 수 있습니다. PDF와 사진 글자는 브라우저에서 인식하고, HWP·HWPX는 문서에 입력된 글자를 브라우저에서 추출합니다. 한글 문서 안에 그림으로 들어간 글자는 읽히지 않을 수 있으니 원본과 대조해 주세요.
3. 활동유형에 체크 표시가 인식되면 해당 유형과 실적을 확인하고, 필수 실적 항목을 입력합니다.
4. ‘작업 저장’을 누르면 기록과 첨부 파일을 이 브라우저에 저장합니다. ‘저장한 일지’에서 활동가 이름과 월을 골라 다시 열 수 있습니다.
5. 모든 날짜를 확인 완료한 뒤 한글 출근부, 출근부 자료(CSV), 월별 한글 문서를 내려받습니다.

## 저장과 개인정보

GitHub Pages는 정적 웹사이트라 계정 로그인이나 서버 저장 기능을 제공하지 않습니다. 입력 내용과 첨부 파일은 사용 중인 브라우저에만 저장되므로 같은 컴퓨터와 브라우저에서 다시 확인할 수 있습니다. 브라우저 데이터를 지우거나 다른 기기를 사용하면 기록을 볼 수 없으니 중요한 문서는 내려받아 보관해 주세요. PDF·사진 OCR에 쓰이는 공개 라이브러리는 처음 사용할 때 인터넷에서 내려받습니다.

로그인 후 여러 기기에서 저장 기록을 이어 쓰는 기능은 [일지 자동 입력 사이트](https://volunteer-journal-yayan.ohjiye.chatgpt.site)에서 이용할 수 있습니다.
