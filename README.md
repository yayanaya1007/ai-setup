# 일지정리

자원봉사 활동을 날짜별로 정리하고, 가야곡 거점캠프 출근부 서식 그대로 한글 문서로 내려받는 웹앱입니다.

## 사용 방법

1. 월을 선택하고 활동가 이름을 직접 입력합니다.
2. PDF·HWP·HWPX·JPG·PNG 활동일지를 올립니다. HWP/HWPX 문서의 글자와 PDF·사진의 글자를 브라우저에서 읽어 날짜별로 정리합니다.
3. 원본 연도가 틀리면 "원본 연도 보정"에 연도(예: 2026)를 입력하고 올리거나 다시 읽으세요. 원본에서 2025년이 읽히면 경고가 표시됩니다. 날짜를 읽지 못한 쪽은 실제 날짜를 직접 입력하며, 쪽 번호를 날짜로 넣지 않습니다.
4. 달력 날짜를 눌러 시간칸과 내용칸에 나뉜 내용을 원본과 대조하고, 활동가 이름 확인에 체크합니다. PDF 활동사진은 분리 가능한 이미지일 때 사진 목록에 들어갑니다. 문서 전체가 스캔된 경우 사진을 직접 올려 주세요.
4. ‘작업 저장’을 누르면 기록과 파일을 이 브라우저에 저장합니다.
5. ‘HWPX 출근부 받기’를 누르면 원본 쪽 여백과 표 모양을 유지한 출근부를 내려받습니다. HWP 파일이 필요하면 HWPX를 한글에서 연 뒤 ‘파일 → 다른 이름으로 저장 → 한글 문서(.hwp)’를 선택하세요.

활동 기록이 없는 날짜의 활동시간 칸에는 `00:00~` 다음 줄 `00:00`이 표시되고, 출장 칸은 비워 둡니다. 이름·날짜·시간 및 서명처럼 입력되는 값은 웹앱이 만든 문서에만 들어가며, 서식 파일과 함께 GitHub에 저장되지 않습니다.

## 저장과 개인정보

GitHub Pages는 정적 웹사이트라 로그인이나 서버 저장을 제공하지 않습니다. 일지와 올린 파일은 사용 중인 브라우저에만 저장되므로 같은 컴퓨터와 브라우저에서 다시 열 수 있습니다. 브라우저 데이터를 지우거나 다른 기기를 사용하면 기록을 볼 수 없으니 중요한 문서는 내려받아 보관해 주세요. PDF·사진 글자 인식에 쓰이는 라이브러리는 처음 사용할 때 인터넷에서 내려받습니다.

## 컴퓨터에서 미리 보기

Node.js가 설치되어 있다면 프로젝트 원본에서 `pnpm install` 후 `pnpm run dev`를 실행합니다.
